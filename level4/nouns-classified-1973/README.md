# Level 4 nouns classified 1973

This folder contains one system-QA-passed Level 4 master for each of the 1,973 source images in `nouns_classified_1973/`.

Every master is a native 1254x1254 RGB PNG. System QA includes the repository mechanical checker and agent visual inspection against `references/SPEC.md`; it is not human approval.

`manifest.tsv` maps every source image to its packaged master and records the SHA-256 digest and design note.
