# Optional prompt guide

Use this only as a starting point. Adapt it to the human request and the image
tool. Do not treat the wording as a fixed profile.

## A useful prompt shape

1. State one character, target Level, and the human's visual direction.
2. Give each attached image one role. Do not say only “use all references.”
3. Describe one dominant design thesis rather than a parts checklist.
4. State the target Level construction.
5. Add the LCD block below when face accuracy is important or a prior attempt
   failed.
6. End with full-body, white-background, brightness, and native-file requests.

For reference mode, a useful priority is:

1. LCD face master controls the LCD, eyes, pupils, and inner glow.
2. aachat master spec controls integration and composition.
3. The human's source image controls motif, silhouette, palette, costume, and
   prop.
4. The Level anchor controls construction and rendering only.

## LCD correction block

```text
Integrate exactly ONE horizontal 1.65:1 deep-black LCD physically into the
head. The opening, frame, seams, depth, and perspective must belong to the head;
the LCD must not float, drift off-center, detach, overlap incorrectly, or look
like a sticker.

Keep a restrained electric-cobalt-blue INNER gradient glow clearly visible
inside the black glass, concentrated behind and around the eyes. Do not omit
the blue glow and do not turn it into a large halo outside the screen.

Show exactly TWO identical, level white square eyes, equal in size and aligned
on one horizontal line with an even gap. Put exactly ONE identical tall narrow
black rectangular pupil inside each white square. BOTH pupils must use the SAME
slight offset to the RIGHT. Never center either pupil and never mirror their
direction.

Keep the LCD close to front-facing, fully visible, and unobstructed. Add no
mouth, nose, brows, lashes, cheeks, glasses, extra eyes, symbols, letters,
icons, or other facial marks.
```

## Completed concept-mode example

```text
Create exactly one original, production-ready, full-body Level 4 aachat
character: a monsoon observatory carried as a living instrument.

Use the attached LCD face master only for the exact screen identity. Use the
Level 4 anchor only for coarse block-built 3D construction, brightness, and
rendering quality; do not copy its white-blue character design.

Build one unified weather-observatory silhouette from conspicuous large square
3D modules: a broad rain-gauge head shell, stepped cloud-catching shoulders,
and one compact brass wind vane integrated as a necessary instrument. Use deep
teal ceramic, rainwater blue glass, and small brass accents. Keep the same
coarse module scale across the head, LCD housing, body, clothing, limbs, shoes,
and prop. Do not apply a pixelation filter to a smooth model.

Integrate exactly one horizontal 1.65:1 deep-black LCD physically into the
head. Keep the cobalt-blue inner gradient glow visible. Show exactly two
identical level white square eyes. Each eye contains one identical tall black
pupil with the same slight RIGHT offset; never center or mirror the pupils.
Keep the screen frontal, aligned, unobstructed, and free of every other facial
feature.

Native 1254×1254 RGB PNG. Exactly one character. Show the complete body, hands,
feet, both soles, vane, and every extension inside frame. Opaque seamless white
background, maximum-bright high-key studio lighting, no scenery, text, logo,
watermark, floor line, gradient, or extra character.
```

## Reference-mode adaptation

Use the same section order as the concept example, not its monsoon concept or
Level wording. Replace the design paragraph with a short description extracted
from the supplied source. State explicitly:

```text
The supplied source controls the motif, silhouette logic, palette hierarchy,
costume geometry, prop relationship, and mild pose only. Preserve that design
language, but replace the complete original face system with the aachat LCD.
Do not copy source eyes, mouth, glasses, text, logos, protected identity,
background, or image artifacts. Redesign the head structurally around the LCD;
never paste the screen over the old face.
```

## Three Level 5 evolutions

Use the same system-approved Level 4 as the source for all three children.
Prompt each child separately with one distinct evolution thesis and its
one-word evolution term. Preserve at least two Level 4 anchors, transform at
least three axes, and do not use color changes as the main distinction.
